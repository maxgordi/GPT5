# LG 50LF652V (webOS 2.0) — разгрузка по SSAP

Запускать на компьютере **в той же Wi-Fi сети**, что и ТВ (Python 3.9+).

```bash
pip install -r requirements.txt
python lgtv.py find        # найти IP (SSDP + скан портов 3000/3001), IP -> lgtv_config.json
python lgtv.py pair        # на ТВ появится запрос — подтвердить пультом; ключ -> lgtv_config.json
python lgtv.py apps        # все приложения (id, название, системное, удаляемое) + запущенные; apps.json
python lgtv.py remove      # покажет список скачанных (кроме YouTube), удалит только после «да»
python lgtv.py close       # покажет фоновые приложения, закроет только после «да»
python lgtv.py settings    # прочитать (без изменения) фоновые настройки, доступные через API
python cleanup.py          # закрыть всё фоновое одной командой (кроме YouTube и ТВ), без вопросов
```

Что оставляется всегда: `KEEP_APPS` в `lgtv_common.py` (YouTube, Live TV, HDMI, Home).
Системные приложения никогда не удаляются; закрываются только из списка `CLOSABLE_SYSTEM`.

## Ограничения webOS 2 (без рута)
- Удаление приложений через SSAP, скорее всего, вернёт `401` — тогда удалять с пульта:
  Home → приложение в ленте → долгое OK / «карандаш» → «Удалить».
- Отдельного метода «список запущенных» нет: скрипт пробует `system.launcher/getAppState`
  по каждому приложению; если не поддерживается — видно только приложение на экране,
  а `close`/`cleanup.py` закрывают всех кандидатов «вслепую» (незапущенные просто пропускаются).
- Запись системных настроек (`settings/setSystemSettings`) сторонним клиентам на webOS 2 закрыта.

## Что выключить с пульта (Настройки ⚙ → Все настройки)
- **Общие → Live Plus → Выкл** (ACR, распознавание контента).
- **Общие → Сведения о ТВ → Пользовательские соглашения**: снять согласие на сбор данных
  о просмотре / интерактивную рекламу (названия пунктов зависят от региона прошивки).
- **Общие → Сведения о ТВ → Автоматическое обновление → Выкл** (прошивка).
- **LG Content Store → Мои приложения / настройки → автообновление приложений → Выкл** (если есть).
- **Общие → Быстрый старт** — ВКЛ ускоряет включение ТВ (ценой дежурного энергопотребления).
- **Общие → SIMPLINK (HDMI-CEC)**, **Включение ТВ с мобильного** — выкл, если не нужны
  (но «ТВ с мобильного» нужен для работы этих скриптов).
- Изображение → **Энергосбережение → Выкл/Минимум** на скорость интерфейса не влияет.
