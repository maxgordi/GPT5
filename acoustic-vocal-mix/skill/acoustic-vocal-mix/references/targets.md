# Ориентиры в цифрах

Это стартовые точки из общепринятой студийной практики, а не законы. Если есть референс (особенно разделённый на стемы), цели берутся из него: анализатор покажет точные отличия. Имена метрик совпадают с полями `report.json`.

## Запись

| что | ориентир | метрика анализатора |
|---|---|---|
| формат | 24 бит (или 32 float), 48 кГц | `sr` |
| пики при записи | −12…−6 dBFS, ни одного клипа | `sample_peak_dbfs`, `clipped_runs` = 0 |
| средний уровень | RMS около −24…−18 dBFS | `rms_dbfs` |
| шум в паузах | ниже −60 dBFS (дома реально −55…−65) | `noise_floor_dbfs` |
| фон сети 50/60 Гц | отсутствует | `health.hum` = null |
| DI и микрофон гитары | сдвиг ≤ 2 сэмпла, полярность normal | `guitar_alignment` |

## Gain staging перед плагинами

- Аналоговые эмуляции (CLA-76, CLA-2A, PuigTec, SSL, J37) рассчитаны на вход около **−18 dBFS RMS (≈ 0 VU)**. Подгоняй Clip Gain (в движке `clip_gain_db`).
- Каждый плагин по возможности **громкостно нейтрален** (makeup/output), чтобы сравнение bypass/on было честным.

## Вокал

| что | ориентир |
|---|---|
| HPF | 70–100 Гц (низкий мужской 60–80, женский 90–120), 12–24 dB/окт; проверка по `band:sub`/`band:low` и плозивам |
| компрессия, суммарно | 6–10 dB подавления на пиках (поп), 4–8 dB (камерная акустика); в 2 ступени: быстрая 3–6 dB + медленная 2–4 dB |
| 1-я ступень (1176-тип) | ratio 4:1, attack быстрый (на 1176 ручки attack/release около 3 и 7 часов, или 1–5 мс в Pro-C 2), release 50–100 мс |
| 2-я ступень (LA-2A-тип) | opto, 2–4 dB; Pro-C 2 Opto/Vocal: ratio 2–3:1, attack 10–30 мс, release 150–400 мс |
| де-эссер | 3–6 dB подавления только на «с/ш/ч», 5–9 кГц (мужской ближе к 5–7, женский 6–9) |
| ровность готового вокала | `consistency.spread_p90_p10` = **4–8 LU** (сырой вокал обычно 10–16) |
| сибилянты | `sibilance_peak_vs_body_db` ≤ **−6 dB** или не выше референса +2 dB |
| плозивы | `plosive_count` = 0 после обработки |
| «воздух» | +1.5…+3 dB полкой 10–12 кГц, если `band:air` ниже референса |

## Акустическая гитара (пьезо + микрофон)

| что | ориентир |
|---|---|
| HPF | 60–90 Гц, если гитара единственный низ; 100–150 Гц, если есть бас или фортепиано |
| пьезо-кряк | срез −2…−5 dB, Q 1.5–3 где-то в 1–2.5 кГц (ищи свипом или по `resonances`); лучше динамически или soothe2 |
| компрессия | 2–5 dB, ratio 2–4:1, attack 10–30 мс (сохранить щипок), release 80–200 мс |
| динамика | `spread_p90_p10` 3–6 LU для аккомпанемента |
| расчистка под голос | −2…−4 dB в 1–4 кГц только пока звучит вокал (`spectral_duck` / Pro-Q dynamic + sidechain / TrackSpacer) |

## Баланс голос ↔ гитара

| что | ориентир |
|---|---|
| `vocal_over_guitar_lu.median` | равно референсу ±1.5 LU; без референса начни с **+3…+6 LU** (вокал явно впереди) |
| `intelligibility_zone_1_4k_guitar_minus_vocal_db` | ≤ −3 dB (голос доминирует в зоне разборчивости) |
| `masking_bands` | красных полос нет или 1–2 узкие |

## Пространство

| что | ориентир |
|---|---|
| plate на вокал | decay 1.2–2.2 с (баллада до 2.5–3), pre-delay 20–80 мс (или 1/64–1/32 такта), HPF 200–500 Гц / LPF 6–10 кГц на возврате, де-эссер на возврате |
| посыл на ревер | обычно −15…−25 dB (post-fader); ревер «чувствуется, но не слышится» отдельно |
| room для «клея» | decay 0.4–0.8 с, тихо, общий для голоса и гитары |
| дилей | 1/4 или 1/8 с точкой, feedback 15–35 %, HPF 300–500 Гц / LPF 3–6 кГц, дакинг от сухого вокала; slapback 80–140 мс для «живого» камерного звука |
| время дилея | четверть = 60000 / BPM мс; восьмая = /2; восьмая с точкой = четверть × 0.75; триоль = × 2/3 |

## Стерео

| что | ориентир |
|---|---|
| `stereo.correlation` микса | > +0.3; доля времени с отрицательной < 5 % |
| `low_side_to_mid_db` | < −20 dB (низ ниже 150 Гц почти моно) |
| `balance_l_minus_r_db` | ±1 dB |
| вокал | центр, сухой сигнал моно |

## Шина и мастер

| что | ориентир |
|---|---|
| пики микса перед мастерингом | −6…−3 dBFS, без лимитера на шине |
| компрессор шины | 1–2 dB, ratio 2:1, attack 10–30 мс, release auto |
| громкость мастера (акустика, стриминг) | −14…−11 LUFS-I; громче смысла нет: Spotify/YouTube нормализуют к ~−14, Apple Music к −16 |
| true peak | ≤ −1.0 dBTP (если мастер громче −10 LUFS, лучше −2 dBTP) |
| PLR | ≥ 9 dB; камерная акустика часто 11–14 dB |
| LRA | обычно 5–10 LU у песни «голос + гитара» |

## Наклон спектра

`tilt_db_per_oct` сам по себе ничего не значит: сравнивай с референсом. Разница больше ±0.8 dB/окт означает, что микс в целом ярче или темнее референса. Правь широким наклоном (Pro-Q tilt shelf, Baxandall), а не десятью колоколами.
