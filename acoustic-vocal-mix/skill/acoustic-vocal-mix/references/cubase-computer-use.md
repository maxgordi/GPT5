# Cubase + computer use: как Claude видит и крутит

## Главное ограничение

Computer use работает по шагам «скриншот → действие». Скриншот сжимается, мелкий текст теряется, видео нет: движение метров между кадрами не видно. Отсюда правила:
- **Оценивать звук** экспортом и `mix_analyzer.py`, а не по скриншотам метров.
- **Скриншоты** для навигации, чтения значений параметров и чтения **интегральных** показателей (Integrated LUFS, LRA, max True Peak, усреднённый спектр) после полного проигрывания фрагмента.
- Точные значения вводить с клавиатуры, а не тянуть мышью.

## Однократная подготовка проекта (делает пользователь, Claude подсказывает)

1. **Монитор/разрешение:** 1920×1080 или 2560×1440, масштаб Windows 100–125 %. Чем крупнее UI, тем лучше читаются цифры.
2. **Workspace «Claude Mix»** (Window → Workspaces): MixConsole на весь экран, Channel Settings одного канала, окно метров. Сохрани и повесь на горячую клавишу.
3. **Именование:** треки `VOX`, `GTR DI`, `GTR MIC`, FX-каналы `FX Plate`, `FX Delay`, `FX Room`. По именам Claude находит нужное на скриншоте.
4. **Цвета:** вокал, гитара и FX разными цветами.
5. **Измерители на Stereo Out** (последний слот, post-fader):
   - **SuperVision** (штатный в Cubase): модули Loudness (Integrated, Short-Term, LRA, True Peak), Spectrum Curve, Phasescope + Correlation, Level. Окно растянуть, тема контрастная.
   - **Youlean Loudness Meter 2** (бесплатный): крупные цифры, история громкости, кнопка сброса. Лучший измеритель для скриншотов.
   - **iZotope Tonal Balance Control 2**: показывает коридор «нормального» спектра для жанра. Claude видит, вышла ли кривая из коридора. Очень наглядно на скриншоте.
6. **Маскировка на гитаре:** Pro-Q 3/4 на гитаре и на вокале. В Pro-Q гитары включи показ спектра другого экземпляра (вокала): видно наложение спектров и места столкновений. Штатная альтернатива: Spectral Comparison EQ в Channel Settings (Cubase 12+).
7. **Масштаб плагинов:** у FabFilter размер окна L/XL; у Valhalla и Waves увеличение окна, если поддерживается.
8. **Сайдчейн:** на гитаре Pro-Q dynamic bands с внешним сайдчейном (включить Side-Chain в окне плагина, на вокале Send → Side-Chain гитарного Pro-Q).

## Протокол действий Claude в Cubase

1. Перед правками: File → Save New Version. Каждый этап получает новую версию.
2. Открыть Workspace «Claude Mix», сделать скриншот, проверить, что треки и плагины на месте.
3. Одно действие → скриншот → проверка: значение именно то, что нужно (при необходимости увеличь область скриншота).
4. **Ввод значений:**
   - у многих плагинов (FabFilter и другие) значение вводится с клавиатуры двойным кликом или по клику на числовое поле. Проверь в начале сессии и запомни, как это работает у каждого плагина;
   - **Generic Editor:** контекстное меню окна плагина → Switch to Generic Editor. Параметры видны списком с числами. Ввод текста там может не работать, но числовое значение видно, и его можно двигать с шагом;
   - штатные Channel Settings (EQ, Strip) показывают числа. Удобно для HPF, EQ, гейта и компрессора;
   - фейдеры, панорама, посылы: двойной клик по числовому полю в MixConsole → ввод числа → Enter.
5. **Перенос из движка:** открыть `cubase_recipe.md` и идти по слотам сверху вниз. Для VST3 загрузить `.vstpreset`:
   - простой путь: окно плагина → менеджер пресетов → Import/Load из файла (если плагин позволяет);
   - через папку: сохрани из Cubase любой пресет этого плагина и посмотри, в какую папку он лёг. Обычно это `Documents\VST3 Presets\<Vendor>\<Plugin>\` (Windows) или `~/Library/Audio/Presets/<Vendor>/<Plugin>/` (macOS). Положи туда файлы из `presets/`, они появятся в браузере пресетов.
6. **Замер в Cubase:** выбрать цикл (весь куплет и припев) → сбросить Youlean/SuperVision → проиграть весь цикл → **после** остановки скриншот → прочитать Integrated / LRA / max TP. Один скриншот во время игры случаен, не делай по нему выводов.
7. **Экспорт для анализатора:** File → Export → Audio Mixdown → Channel Batch Export (VOX, GTR…, FX) + Stereo Out, WAV 24 бит или 32 float, от начала проекта. Затем `mix_analyzer.py analyze … --previous` по прошлому отчёту.
8. Не закрывать проект без сохранения. Не применять Render in Place, Direct Offline Processing или удаление без явного «да» пользователя.

## Продвинутый путь без мыши: MIDI Remote

Cubase 12+ поддерживает MIDI Remote (скрипты на JavaScript, в 15.0.30 API 1.3). Схема: виртуальный MIDI-порт (loopMIDI на Windows, IAC на macOS) → скрипт MIDI Remote маппит CC на Quick Controls трека или фокусного плагина → Python (`mido`) отправляет точные значения. Плюсы: точность и скорость. Минусы: 7-битные CC (128 шагов) грубоваты, маппинг надо настроить один раз. Это стоит делать, только если перенос пресетами и рецептом не устраивает.

## Что Claude не должен делать по скриншотам

- Судить о сибилянтах, мутности или «дороговизне» звука по картинке спектра в моменте.
- Подбирать атаку и релиз компрессора по прыгающей стрелке подавления.
- Делать вывод «громкость правильная» по Momentary/Short-Term в одном кадре.

Для всего этого есть экспорт и анализатор.
